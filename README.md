# 卒業論文

## 作成物の説明（何を作ったのか／目的・背景）

本研究では、文章情報と表情情報を活用したマルチモーダルRAG対話システムを作成した。
目的は、ユーザの発話内容だけでなく、表情から読み取れる感情状態も考慮し、より利用者に適した応答を生成することである。

従来の対話システムでは、主にテキスト情報をもとに応答を生成するため、ユーザの非言語的な状態を十分に反映できないという課題がある。そこで本研究では、発話文に加えて表情特徴量を活用し、動機づけ面接におけるカウンセラー応答の質を高めることを目指した。

本リポジトリでは、卒業論文PDFを公開している。

## 直面した課題と解決方法

研究を進める中で、表情情報を単純に入力へ追加しても応答精度が十分に向上しないという課題に直面した。
原因として、テキスト情報と表情情報の性質が異なり、単純に結合するだけでは生成AIが表情情報を適切に活用できない可能性があると考えた。

そこで、以下の複数手法を比較した。

* テキスト情報のみを用いる手法
* 表情特徴量を自然言語の注釈として追加する手法
* テキストベクトルと表情ベクトルを結合する手法
* テキスト情報と表情情報を分離して検索する手法

その結果、表情情報をそのまま結合するのではなく、自然言語化したり、テキスト情報とは分けて扱ったりすることが有効であると確認した。
この検証を通じて、マルチモーダル情報を対話生成に活用する際には、単に情報を追加するだけでなく、生成AIが利用しやすい形に変換・設計することが重要であると学んだ。

## 技術情報（使用モデル、API、アーキテクチャ、実装方法）

本研究では、RAGを用いた対話生成システムを構築した。
主な技術情報は以下の通りである。

* 使用言語：Python
* 使用モデル：GPT系大規模言語モデル
* 使用API：OpenAI API
* 埋め込みモデル：text-embedding系モデル
* 表情特徴量：OpenFaceにより抽出したAction Unit特徴量
* 検索方式：ベクトル検索
* アーキテクチャ：Retrieval-Augmented Generation（RAG）
* 実装内容：

  * 対話文の前処理
  * 発話文のベクトル化
  * 表情特徴量の抽出・正規化
  * 類似事例検索
  * 検索結果を用いたプロンプト作成
  * 生成AIによる応答生成
  * 複数手法の比較評価
